# Smart Study Planner

An AI-assisted study planning workflow built using Langflow.

## About the Project

Students often have to manage several subjects, assignments, and study activities at the same time. Without proper planning, it can be difficult to decide what to study first and how to divide available study time.

Smart Study Planner was created to explore how Generative AI can be used to help organize study activities based on information provided by the user.

## Project Objectives

The objectives of this project are:

- Create a simple study planning workflow
- Use user input to generate study recommendations
- Explore the use of Large Language Models in a practical use case
- Learn how to build an AI workflow using Langflow

## How It Works

The workflow takes study-related information from the user and processes it through an AI workflow.

The basic process is:

User Input → AI Processing → Study Recommendations

The generated recommendations are based on the information provided by the user.

## Features

- Accepts study-related user input
- Generates study recommendations
- Uses a Large Language Model
- Built as a visual workflow in Langflow

## Impact

The project can help students organize their study activities by providing recommendations based on their available information.

For users, the main benefit is having a starting point for deciding:

- What to focus on
- How to organize study activities
- How to use their available study time

The project is a prototype, so the recommendations are intended to support planning rather than replace a student's own decision-making.

## Tools

- Langflow
- Generative AI
- Large Language Models (LLMs)
- Prompt Engineering
